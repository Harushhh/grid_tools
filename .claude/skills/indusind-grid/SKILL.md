## Run it
```
.venv/Scripts/python.exe indusind_grid_to_config.py --grid "<grid>.xlsx" --from-date DD/MM/YYYY --to-date DD/MM/YYYY --ref "<their last export>.csv" --no-prompt
```
Output `output\indusind\INDUSIND_UPLOAD_<yyyy-mm>.csv` + `INDUSIND_REVIEW_<yyyy-mm>.xlsx` (Summary, Not written, RTO groups to create, Changed vs earlier upload, Manual review notes, Notes read, Unread parts when something is unread). **from_date and to_date are given on EVERY run** (Rules 7): without them a run that cannot ask stops.

## How it reads the grid - nothing by a cell address
`find_anchor` finds the header row by its words (a cell that says 'RTO Region' - usually twice - with at least three header columns to its right); `RateTable` carries merged cells into every column they cover and builds the CHAIN of each payout column (make label / segment / leaf, any number of rows, a blank row inside the band does not end it, a banner over every column is a note). `classify_chain` reads the words: a text is a SEGMENT (names a product), a LEAF (Comp / STP / All / fuels / Fresh) or a MAKE LABEL (makes, 'Others'); every word is USED UP by a pattern and a word nobody understands REFUSES that column (warned, listed in 'Unread parts', never guessed). Tables: `SEG_PATTERNS`, `BODY_TYPES` (T&C of Flat Bed / JCB / Tractor / Car Carrier), `MAKE_WORDS`, `MAKE_SETS` (the master's own groups for a make set), `FUEL_WORDS`. A visible sheet that says a region header over product columns is the table; a table whose columns no rule reads is another product (Private Car, TW Scooter, Short Term Taxi: 'Not written'); two sheets with the same products ask which is this month's (a stop with `--no-prompt`).
Region column: when two columns say 'RTO Region' (parent + cluster) the one with MORE distinct names is the cluster (decided by the values, so a swap does not matter); two with the same count and different names STOP. **October 2026 layout** (see `INDUSIND_GRID.md` section 14): any short cell with 'region' / 'cluster' says a region (never a code column; the parent column may say no 'region' at all - it is found by its values); a header chain may name its product TWICE (a group title over a sub-title): merged when the texts agree, the column refused when they conflict; a Private Car / two-wheeler column inside the sheet is another product (listed in 'Not written'); the workbook's own `RTO List` sheet gives did-you-mean hints and RTO codes; `INCOMPLETE: n of m payout columns were not read` is the first warning when a column was refused.

## Validations (what makes a run trustworthy - check each before saying "done")
- **Shape**: rows = regions x 157 for the November layout (11,461 for 73 regions) and x 122 for the October layout (8,784 for 72 regions: 5,369 zero cards); every region gives the same number of rows; `Zero cards` and `PO floored to 0` are printed (7,970 and 39 in November) - a jump means a column was refused or a header changed.
- **Warnings**: every `WARNING:` line is a column / sheet that is NOT in the upload (a refused header, an unrelated text sheet, hidden rows with payouts, many blank cells): read each one; the review sheet `Unread parts` lists them. A refused column is a header word nobody understands - add the wording to the tables (`SEG_PATTERNS`, `BODY_TYPES`, `MAKE_WORDS`, `FUEL_WORDS`, `LEAF_WORDS`) AND a test in `tests/indusind_tests.py`, never hard-code the month's number.
- **Against their export (`--ref`)**: new rows = new regions (Indore), removed rows = another product's rows, changed rows = listed one by one (log + `Changed vs earlier upload`); explain every number. November: 157 new / 79 removed / 34 changed.
- **Spot-check 3-5 cells BY LABELS with openpyxl** (rule 7 of CLAUDE.md; never by a typed address): the Mumbai cluster row x the `School Bus / All` header chain, x 100 = `pi_net_rate` of the Mumbai school-bus 1+1 Petrol row, `pi_tp_rate` of its STP row, po = pi - 7 (floor 0); the same row under the make label `TATA / Maruti / Mahindra ( Only Jeeto & Supro )` -> `TATA,Maruti,Mahindra`; the same row under `PCV TAXI <6 Str ( NND)` / `Diesel - Comp & STP` -> Mumbai diesel taxi (25, not the export's 15).
- **Names**: no leading / trailing space in any text column; every make group is in the make master (the run says "every make name written is in them"); `RTO groups to create` lists the regions without a group (Indore); `Make groups to create` must stay empty.
- **Flags**: 11,461 flagged is expected until the user resolves the hygiene / specific-deals notes; the two qualifier blocks (GCV < 2 T and 2-2.5 T) and Kaali Pili / School Bus / LCV notes are scoped (see `Manual review notes`); the Car Carrier guard fires only when a Car Carrier cell is above 0.
- **Tests**: `.venv/Scripts/python.exe tests/indusind_tests.py` (167 checks) - `python check_regressions.py --only indusind_nov26` - `SHIFT_ONLY=indusind python tests/structure_shift_tests.py` (a re-laid-out grid gives the same upload or a clear STOP) - `python tests/unread_audit.py indusind_nov26 --mode columns` (no SILENT column: every column is READ or MENTIONED). Never `--bless` to hide a difference.

## Traps seen
- The user's export had trailing spaces in two make names (1,440 rows, invisible in a printout): the comparison folds names (`REF_MAKE_ALIASES`); the upload never carries a trailing space (test `no text cell ... leading / trailing space`).
- Two 'RTO Region' columns: the parent (36 distinct names) and the cluster (73 distinct, one per row): decided by the values.
- The master's `TAXIALL_*` groups are NOT the union of the single-make groups (138 entries vs 197): a table of names (`MAKE_SETS`), not a by-content lookup.
- openpyxl `insert_rows` / `delete_cols` do not move merged ranges: a test that builds a shifted grid must use `shiftlib.insert` (tests of banners / twin columns once failed for this reason).
- A `\b` typed inside a NON-raw Python string becomes a backspace character: write regexes with a raw string (the first `band_of` patch silently matched nothing).
- The master has make groups for the qualifier (`JEETO_SUPRO`, `MAHINDRA_EX_JEETO_SUPRO`, `GCV4W_ALL_EX_TATA_MARUTI_MAHINDRA_JEETO_SUPRO`, `Mahindra_Supro` ...): the qualifier is still only FLAGGED (the user's export writes the plain makes).
- (23 Nov 2026) The user's October export (92) names things differently from the November one: PCV_4W_ALL for BUS_ALL / TAXI_ALL, the master's Jeeto / Supro groups (TATA,Maruti,JEETO_SUPRO and GCV_4W_ALL_EX_TATA_MARUTI_JEETO_SUPRO), 'JCB,Caterpillar' (no L&T), the T&C 'Non,Kalli Pilli' on the ordinary <6-seat taxi cards and a nil-dep DIESEL taxi row. They are listed, never applied: November must stay byte-identical. A hint from the RTO List needs a clearly closest free name (alike >= 0.45, margin 0.15): with a small grid the list has many free names. A shift operator that adds a column or blank row inside the M & HCV text table changes the quoted note: REMARKS by design.
