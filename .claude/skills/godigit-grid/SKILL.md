## Run it
```
.venv/Scripts/python.exe godigit_agency_to_config.py --grid "Delhi_PAN_India_Agency.xls" --password "<password>" --from-date DD/MM/YYYY --to-date DD/MM/YYYY --ref "<their export>.csv" [--no-prompt]
```
The password comes from `--password`, the environment variable `GRID_PASSWORD`, or a hidden prompt - **never stored in a file or a doc**. `msoffcrypto-tool` (in `requirements.txt`) decrypts the OLE container; `xlrd` is only for a genuine old .xls. The web app sets `GRID_PASSWORD` for the child process.

## How the workbook is read
- **Nothing is found by a sheet's name or a column's place (since 10 Nov 2026, P-56): every table is found by what its header row says; the sheet names below are OCTOBER's, the November workbook calls them `CV Grid`, `New 2W Comp & SATP wef 1st Nov`, `2W Grid 1+5`, `2W SAOD`, `New 4W Comp_SAOD `, `4W TP Consolidated`, `Remarks for CV`, `RTO Mapping` / `4W RTO Mapping - New` / `2W RTO` (13 sheets, none hidden).**
- October: 26 sheets, 14 HIDDEN = older versions, never read (`sheet.visible`). Read: `LATEST CV COMBINED GRID` (GCV 4W / 3W, taxi, staff bus, PCV 2W / 3W, MISCD, tractors; CD1 = the OD-discount band, CD2 by vehicle age for comprehensive and SATP), `Latest 2W 1+1 & SATP`, `2W 1+5` (only the block with "1+5" written above), `Latest 2W SAOD`, `PVT Car Comp+SAOD`, ` PVT Car TP` (leading space), `CV Remarks` (Volvo / Scania blocked; Truck Mahindra + Bharat Benz at 70% CD1), the mapping sheets (only to put RTO codes next to a group the master lacks). Not converted: `2W Grid 5+5`, old `2W_SAOD`, School Bus, car new business and 3+3.
- Comprehensive = 1+1 On Net, SATP = STP On TP (always tariff 0-100.01, NCB / ZD `NA`). Ages New 0-1 (add_tnc `New`), 1 Yr 1-2 ... 6-10 Yr, 11+ Yr. Cells are fractions (0.325 = 32.5). CD1 -> `tariff_max = cap + 0.01`; its text forms are many (`0-60%`, `New/1yr: D | 2-5yr: 80% | 6yr+: 85%/90%`, `With Addon: 85%/90% Without Addon: 60%` -> is_zd YES / NO ...); a NEGATIVE CD1 = declined (zero card at 100.01); formula noise in a CD1 is written as the whole percent and flagged.
- RTO group `GO-DIGIT_OCT26_<segment>_<cluster>` (2W `GO-DIGIT_OCT26_2W_1+1_TP_` / `_2W_SAOD_`, cars `GO-DIGIT_PC_1+1_OCT26_` / `_PC_SAOD_OCT26_` / `_PC_TP_OCT26_`) resolved to the master's spelling; a missing group is flagged and listed with its RTO codes. `D` / `#VALUE!` = a zero card, blank = placeholder, `MISP` = On OD 17.5 (not in the grid; the October upload's value, flagged).
